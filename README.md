# AURON 2.0

AI Powered Desktop Assistant built using Python and Ollama.

## Features

- AI Chat
- Voice Commands
- Hotkey Activation
- Long-Term Memory
- Vector Memory
- Sticky Notes
- Task Manager
- Focus Mode
- Pomodoro Timer
- Daily Planner
- Daily Standup Generator
- Email Assistant
- Calendar Integration
- Authentication
- System Controls

## Technologies

- Python
- CustomTkinter
- Ollama
- ChromaDB
- PyInstaller
